- [CONV-2026-10-02-3a97] WHEN BULK-DRIVING A GOVERNED HTTP ENDPOINT FROM A SHELL LOOP, READ THE ID LIST WITH `while IFS= read -r` AND DO NOT TRUST A TRAILING-NEWLINE-FREE FILE: zsh does not word-split unquoted variables, so `for ID in $IDS` silently iterates ONCE over the whole newline-joined blob, and `while read` silently DROPS the final line when the file lacks a trailing newline. Both failures are silent, both under-report, and both leave a partial governed write. Verify the count dispatched against the count expected BEFORE concluding the batch completed, and re-measure the persisted state afterwards rather than trusting the dispatch loop's exit status. #added:2026-10-02
