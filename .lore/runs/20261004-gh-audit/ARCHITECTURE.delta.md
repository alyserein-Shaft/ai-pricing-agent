# ARCHITECTURE delta — genericHeading bounded to titles

- [ARCH-20261004-ghbound] `genericHeading` in `app/domain/boq-understanding-pilot.mjs` had ONE unbounded alternative, `.+\s+system`, while every other alternative is a SHORT generic scaffolding token (`general`, `scope of works`, `preliminaries`, `notes`, `description`, `bill of quantities`, `for .+`). Left unbounded, it classified ANY scope sentence merely ENDING in the word "system" as `Heading-like row`. It is now bounded to a short title via `(?:\S+\s+){0,7}system` (at most 7 leading words), which preserves real system titles ("Fire alarm system", "Fire detection and alarm system", "CCTV system") while no longer sweeping up quantified deliverable scope rows. Intent preserved, heading detection NOT globally disabled. Live effect on `project_ae501b85-9c12-4332-bf8e-787c90f2d388`: `eligiblePrimaryCount` 73 -> 77 and `excludedDataQualityCount` 10 -> 6, i.e. exactly the four "…interfacing with BMS system" rows were freed and nothing else moved. See `app/domain/boq-understanding-pilot.mjs`. #added:2026-10-04

- [ARCH-20261004-pilotrotate] The controlled BOQ Understanding pilot selects ONE ROW PER TAXONOMY FAMILY via `selectPrimaryByDistinctFamily`, capped by `BOQ_UNDERSTANDING_PILOT_MAX_ITEMS` (12 for this project), AFTER removing rows that already carry an interpretation at the CURRENT config fingerprint (`alreadyInterpretedItemIds`). Two consequences that are easy to misread as bugs. (1) Because exclusion happens BEFORE selection, an eligible row can be perfectly healthy and still be unselected purely because a sibling in the same family already holds that family's slot — this is fairness rotation, not a defect, and the slot frees once the holder is interpreted. (2) Measured live: `alreadyInterpretedItemIds` is currently **0** at the active config fingerprint, so the whole 90-row project is un-interpreted at this config and rotation would eventually reach any given row — but each round only interprets 12 unrelated rows, so reaching 8 specific rows can cost up to ~90 unrelated interpretations. `CONTROLLED_RETRY` is NOT a targeted escape hatch: it requires exactly 6 items drawn from ONE historical run's own quality recommendations, so it cannot authorise an arbitrary set. There is therefore NO existing governed path to interpret a specific named subset without either consuming rotation rounds or changing policy. See `app/domain/boq-understanding-pilot.mjs`, `worker/estimator-understanding-api.mjs`. #added:2026-10-04
